INPIXEL NETWORK — NEW REDESIGNED WEBSITE
=========================================

This package contains the newly redesigned multi-page website.

Quick preview:
1. Extract the ZIP.
2. Open index.html in a modern browser.

Production deployment:
Upload the extracted folder to Vercel and configure the environment variables
listed in .env.example for Supabase, Razorpay, email, and scheduled workflows.

The visible site is powered by styles.css and main.js. Existing workflow
scripts and API files are retained for login, admin, payments, forms, and blogs.
